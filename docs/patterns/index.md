# Patterns

Whole tasks built only from EOS components, with source. If a pattern needs a custom box, the library is missing a building block.

## Forms and flows

- [Pay a bill](/patterns/pay-a-bill): pay a balance in full or in part.
- [Sign in](/patterns/sign-in): a password or a code, an error summary and a new password.
- [Register](/patterns/register): a multi-step form with a stepper and a review step.
- [Sign a form](/patterns/sign-a-form): a list of forms and a typed or drawn signature.
- [Settings page](/patterns/settings): profile fields and switches with one Save and a toast.

## Lists and data

- [Statements](/patterns/statements): search, filter and page a list of expandable rows.
- [Search with filters](/patterns/search-filters): results with a segmented filter, a select and a count.
- [Data table with bulk actions](/patterns/data-table): a DataGrid with selection, a confirm dialog and a toast.

## Pages and states

- [Dashboard overview](/patterns/dashboard): a notice, key figures and recent activity.
- [Empty and error states](/patterns/empty-and-error): loading, error, empty and loaded versions of one list.
