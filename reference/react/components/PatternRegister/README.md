Registration as a short form in steps. Press Continue with the fields empty to see the error handling.

- **Built from:** Stepper, ErrorSummary, FormSection, Field, DatePicker, PhoneField, Actions.
- **Errors:** on a failed submit an ErrorSummary appears at the top and takes focus; the list names each field and what to fix, and each field also shows its own error. Fields keep their values.
- **Fields:** one question per field, with the autocomplete token that lets the browser fill it. Mark what is required, not what is optional, when most fields are required.
- **Steps:** name the steps with what the person is doing. Offer "Save and finish later" so a long registration is never lost.
