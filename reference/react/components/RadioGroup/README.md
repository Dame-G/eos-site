Exactly one of five or fewer options. Props: `label` (the legend), `options` (strings or `{value, label, description, disabled, reveal}`), `value` or `defaultValue`, `onChange(value, event)`, `hint`, `error`, `required` or `optional`, `disabled`, `name`. It is a Fieldset: legend, hint and error are announced with the group. Arrow keys move between options.

- `reveal` is a control that appears under its option while that option is chosen (an amount field under "Another amount"). It spans the full width of the group and sits 4px under the option.
