Cards in as many equal columns as fit. Props: `min` (the narrowest a column may be, default 16rem; one column below that) and `gap` (a space token number, default 4). It responds to the width of its own container, so the same Grid is three columns on the page and one in a drawer. Use it for lists of StatementCards or AppointmentCards. Items stretch to the tallest card in their row, so a card whose name wraps never leaves its neighbours short and each card's actions bar stays level at the foot.
