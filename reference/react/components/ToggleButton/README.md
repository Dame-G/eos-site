A button with two states, pressed and not: a filter, a view option. Props: the label as children, `icon`, `pressed` or `defaultPressed`, `onChange(pressed)` and `disabled`. The state is exposed with `aria-pressed` and shown with a filled tint and a heavier edge, not colour alone; keep the label the same in both states (it names the option, not the state). For settings that save, use Switch.
