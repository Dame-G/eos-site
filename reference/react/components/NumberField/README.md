A number input with decrease and increase buttons. Props: `label`, `value` or `defaultValue`, `onChange(number or null)`, `min`, `max`, `step` (decimals follow the step), `prefix`, `suffix`, `name`, `autoComplete`, `hint`, `error`, `required` or `optional`, `disabled`. Arrow Up and Down step, Shift steps by ten; values clamp on blur and the buttons disable at the limits. For quantities. An amount of money is CurrencyField.
