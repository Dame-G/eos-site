A flat, outlined mark with a glyph that says where something stands. Props: `status` (a preset: `paid`, `due`, `overdue`, `action`, `scheduled`, `confirmed`, `cancelled`, `signed`, `pending`, `complete`) or `tone` (`success`, `info`, `warning`, `danger`) with `label` and `icon`; `detail` (a date or day count), `small` (for rows).

- Success is green, information blue, needs-action amber, a problem red. The word and the glyph carry the meaning; colour backs them up.
- Stamps are not clickable, so they have no depth. A Button never has a glyph; a stamp always does.
