A Button that opens a short list of actions. Props: `label`, `items` (`{label, icon, onClick, danger, disabled}` or `{divider: true}`), `variant` (default `outline`) and `icon`. Items are 48px rows; the first item takes focus when it opens, arrow keys move between items and Escape closes. Put the destructive item last, after a divider. Use it when there are three or more actions and no room for Buttons.
