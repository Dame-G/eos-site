A single yes/no choice. Props: `label`, `description`, `checked` or `defaultChecked`, `onChange(checked, event)`, `disabled`, `required`, `error` (under the row, with `aria-invalid`), `name`, `value`, `id`, `inputRef`, and `indeterminate` (a mixed state, such as select-all with some rows chosen). `bare` hides the label visually but keeps it for screen readers, for a table cell.

The whole 48px row is the target. Checked is a `primary` fill with a white tick; unchecked has a `border-strong` edge. A setting that takes effect immediately is a Switch.
