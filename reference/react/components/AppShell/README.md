The frame of a whole page: a skip link, the header, an optional side navigation, the main content and a footer. Props: `header` and `footer` (an AppHeader and AppFooter), `sidebar` (a NavList), `sidebarLabel`, `mainId` (the skip link's target, default `main`) and the page as children. The main area is a landmark that takes focus when the skip link is used. The side navigation sits above the content below 48rem, and the content is capped at 72rem so lines stay readable.
