The one box you look things up in: a flat outlined field with a Button inside, one per page, at the top. Props: `placeholder` (say what can be searched, briefly), `label` (for screen readers; default "Search"), `action` (the Button's text), `value` or `defaultValue`, `onChange(value, event)`, `onSubmit(value)`, `name` (default `q`), `disabled`. When search is unavailable, disable it and say why in a Notice.
