A section that opens and closes, on the native details element so it works without script. Props: `title`, children, `variant` (`row` default: flush, with a divider above, mono title; `card`: a roomy row for stacking, used by Accordion), `meta` (a short note at the right, card variant), `defaultOpen`, and `group` (rows sharing a group open one at a time). The chevron turns when open. StatementCard uses it for History; use Accordion for a stack of them.
