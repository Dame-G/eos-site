A side panel on the native dialog element: focus is trapped, Escape closes it and the page behind goes inert. Props: `open`, `title`, `onClose`, children, `actions` (Buttons in a tinted footer, left-aligned, main action first) and `side` (`right` default, or `left`). It is full height and 28rem wide, or the full screen width on a phone. Use it to show a statement or receipt next to the list the person is looking through; use Dialog for a short decision.
